# Frequently Asked Questions: TruthGuard Anti-Misinformation Hub

### 1. What is TruthGuard Anti-Misinformation Hub?
Interactive news verification and misinformation detection dashboard with claim classification metrics.

### 2. What technology stack does it use?
Built with React / TypeScript, TailwindCSS, Chart.js.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/27-codealchemist/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
