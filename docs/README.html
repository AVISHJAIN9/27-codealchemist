TruthGuard Platform: Technical Documentation ​

Welcome to the comprehensive, interview-ready documentation suite for TruthGuard: Unified Cyber-Defense, Deepfake Forensics & Optical Tamper Platform (33-codealchemist).

This documentation is crafted in the style of the Vue.js documentation: clear, modular, step-by-step, accompanied by architecture diagrams, exhaustive technical comparisons, spoken interview scripts, and a full system design curriculum.

Complete Reading Order Index ​

1. Foundation & Platform Discovery ​

  • 00. Project Type Classification: Project stack detection (React 18 + TS + Vite + Supabase Edge Functions + Micro-Frontend Hub).
  • 00a. Full Project Analysis: System topology, user journeys, route catalog, full feature traces (F1–F6), inventory counts, and cross-micro-frontend connections.
  • 00b. Project Pitch (30-Second & 2-Minute Scripts): Spoken elevator pitches tailored for hiring managers, technical interviewers, and senior architects.
  • 00. Comprehensive Project Map: Annotated directory tree, dependency audit, environment variable registry, external services, and runtime entry points.

  • Feature F2: Camera Tamper & Optical Obstruction Guard: Real-time optical flow monitoring, canvas-based variance analysis, stream freeze alerts, and spoken defense.
  • Feature F3: Scam Call & SMS Phishing Detector: Heuristic urgency token scanning, natural language sentiment evaluation, phishing URL regex inspection, and spoken defense.
  • Feature F4: MediaVault Cryptographic Provenance: SHA-256 asset hashing, EXIF metadata extraction, immutable chain-of-custody recording, and spoken defense.
  • Feature F5: Unified Hub Threat Intelligence Dashboard: Active cross-port prober, embedded iframe sandbox orchestration, aggregated security event logging, and spoken defense.
