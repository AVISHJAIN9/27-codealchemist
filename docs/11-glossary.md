# Step 12: Technical Glossary & Forensic Lexicon

This glossary defines the digital forensics, cyber-defense, networking, and web development terminology used across TruthGuard.

---

| Term | Technical Definition & Practical Meaning | Context in TruthGuard |
|---|---|---|
| **Deepfake** | Synthetic media generated by deep neural networks (GANs, diffusion transformers) to impersonate human likeness or voice. | The core threat targeted by TruthLence (`F1`) and DeepGuard (`F3`). |
| **Diffusion Model** | Machine learning architecture that generates high-fidelity images by iteratively removing Gaussian noise. | Source of synthetic pixel artifacts identified in `truthlence`. |
| **Error Level Analysis (ELA)**| A forensic technique that identifies areas of an image with differing compression ratios, revealing spliced regions. | Conceptual principle behind TruthLence compression analysis. |
| **EXIF (Exchangeable Image File Format)** | Metadata standard embedded in raster images recording camera hardware, exposure settings, and timestamps. | Parsed by `exifr` in DEEP SCAN (`fileAnalyzer.ts`). |
| **GPS Geotagging** | Latitude, longitude, and altitude coordinates embedded in EXIF tags at the moment of photo capture. | Extracted and plotted on `GpsMap.tsx`. |
| **SHA-256 (Secure Hash Algorithm)** | Cryptographic hash function generating a unique 256-bit (64-character hex) fingerprint from file bytes. | Computed via Web Crypto API in `camara-temper` and `mediavault 2`. |
| **Vishing (Voice Phishing)** | Telecommunication fraud where attackers use synthetic voice cloning or social engineering to extract credentials. | Analyzed in `calldetection-sms-contentdetection/src/pages/CallDetection.tsx`. |
| **Smishing (SMS Phishing)** | Mobile text scams containing deceptive links or urgent requests for financial transfers. | Analyzed in `calldetection-sms-contentdetection/src/pages/SmsDetection.tsx`. |
| **Optical Flow** | The pattern of apparent motion of image objects between consecutive video frames. | Used to detect surveillance camera lens tampering and freeze loops. |
| **Micro-Frontend** | Architectural pattern extending microservices to the frontend, splitting web apps into independent sub-applications. | TruthGuard's federated hub connecting modules running across ports 5173–5184. |
| **Dynamic Port Probing** | Client-side network technique issuing non-blocking HEAD requests to discover active services across port ranges. | Implemented in `FeatureEmbed.tsx` (`checkPort` across ports 5176–5200). |
| **Zustand** | Minimalist reactive state management library for React based on immutable hook selectors without providers. | Powers file queues and activity logs in `mediavault 2/src/lib/mediavault-store.ts`. |
| **Vite** | Frontend build tool that serves code via native ES Modules during development and bundles with Rollup. | Powers local HMR and production builds across all subprojects. |
| **Supabase Edge Functions** | Serverless TypeScript/JavaScript compute workers running on the Deno V8 engine close to clients. | Runs `analyze-media` and `analyze-content` inference pipelines. |
| **Row Level Security (RLS)** | PostgreSQL security feature restricting database rows accessible to a given SQL query based on user identity. | Secures the `profiles` table so users can only access their own data. |
| **GoTrue** | Open-source authentication API supporting JWT issuance, password hashing, and OAuth identity providers. | The authentication engine powering Supabase Auth in `AuthContext.tsx`. |
| **Media Bias/Fact Check (MBFC)**| Independent research organization rating media outlets on factual reporting credibility and political bias. | Grounding standard used for source reliability tiers in `VeritAIApp.tsx`. |
| **Framer Motion** | Physics-based animation library for React enabling fluid gesture controls and staggered transitions. | Powers animated confidence bars, radar sweeps, and card entrance effects. |
| **Lucide Icons** | Open-source SVG icon library designed for modern clean user interfaces. | Provides cyber-defense iconography (`Shield`, `Cpu`, `Phone`, `Lock`). |
| **Tailwind CSS** | Utility-first CSS framework enabling rapid composition of design systems using atomic classes. | Implements TruthGuard's custom NVIDIA-inspired dark styling. |
