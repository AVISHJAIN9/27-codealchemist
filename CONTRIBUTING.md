# Contributing to TruthGuard Anti-Misinformation Hub

Thank you for your interest in contributing to **TruthGuard Anti-Misinformation Hub**! We welcome improvements, bug reports, and design suggestions.

## Code of Conduct
This project follows the [Contributor Covenant 2.1](CODE_OF_CONDUCT.md).

## Development Workflow
1. Fork the repository and create your branch: `git checkout -b feature/your-feature-name`.
2. Commit with conventional semantic messages (`feat:`, `fix:`, `docs:`, `perf:`).
3. Submit a Pull Request describing your changes.
